Pinterest serves whatever size fits the grid — 236, 474, 736 pixels wide. The original file is still sitting on their CDN. Paste image links or pin links below, one per line, and this pulls the uncropped version.
Works best with direct i.pinimg.com image links.
Pin page links (pinterest.com/pin/...) are attempted via a lookup — not always reliable.
How this works: Pinterest's CDN encodes size right in the URL path (/236x/, /474x/, /564x/, /736x/). There's no guarantee an /originals/ file exists for a given pin, so instead of assuming it does, this actually test-loads originals, 736x, 564x, and 474x as real images and keeps whichever one both loads and comes back widest. If nothing bigger resolves, it says so and keeps what you gave it. For pin page links, it fetches the public page and reads the image tag out of it first, which can occasionally fail or get blocked; if so, open the pin, click the image to expand it, right-click → Copy image address, and paste that instead.

Search elsewhere: each result also links out to Google Lens, Yandex, and TinEye's reverse-image search, seeded with the resolved Pinterest URL. Pinterest is usually a re-post of an image originally hosted somewhere else — a photographer's site, a stock library, a blog — and that original host often has a bigger file than Pinterest ever stored. These open the search engines' own results pages in a new tab; there's no automated scraping happening, since none of these sites allow that from a page like this one — it's just a shortcut past typing the URL in yourself.
